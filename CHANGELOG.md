# Changelog

## 0.4.1 — 2026-11-09

- Seek directly in the filmstrip and preview frames on hover. Keep transport controls clear of the timeline input probe.
- Add optional Apple low-latency super resolution, frame interpolation and temporal noise filtering on supported hardware.
- Add debanding, chroma cleanup, edge cleanup and SDR grain, with filter bypass and split and changed-pixel comparisons.
- Lock trackpad gestures to the intended axis, protect clicks from stray scrolling and use SF Symbols by default.
- Keep half-precision grain textures compatible with Intel.

## 0.3.0 — 2026-11-05

- Add Subject Focus to soften or recolour the background around people, with preset looks and a custom panel.
- Add a media catalog, cache controls, file information and viewing history. File View refreshes automatically, including on SMB.
- Add an opt-in TourBox Lite event mode with linear and accelerated scrubbing and separate Viewing and Editing controls.
- Improve network previews, thumbnail readiness and file navigation.

## 0.2.0 — 2026-10-29

- Add a viewing timeline with a thumbnail filmstrip, adjustable time lens, a linear overview and playback controls.
- Keep thumbnail work bounded and suppress hidden-film redraws; improve preview cancellation and background cache filling.
- Add shared slots and refine playlist cards, compact grids and persistent last-opened markers.
- Improve file navigation, window handover and Logitech integration through MouseService.
- Update shared kits and document timeline controls and measured performance.

## 0.1.0

Initial tagged release.
